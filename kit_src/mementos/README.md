# Plans généraux des Mémentos Francis Lefebvre (transcription)

Un fichier `.tsv` par Mémento. Colonnes : `TYPE<TAB>NUM<TAB>TITRE`.

- `P` partie, `T` titre, `C` chapitre : NUM = numéro de la partie/du titre/du chapitre.
- `S` section, `R` subdivision en chiffres romains, `L` subdivision en lettre, `X` divers (intro, annexe) :
  NUM = n° de paragraphe du Mémento (pas une page).
- `N` principale nouveauté de l'édition : NUM = n° de paragraphe.

Transcrit depuis des photos : un n° peut être décalé d'une ligne. Les Mémentos étant numérotés
dans l'ordre, chercher autour du n° donné.
